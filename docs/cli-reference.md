# Intelligence CLI

The supported executable is `attocode-code-intel`. Start with `--help` for the
current command list. Use `init` to configure an MCP client and `doctor` to check
that configuration. `serve` runs the MCP/API server; `setup` prepares local
PostgreSQL/Redis development infrastructure without embedding-model extras.

[Getting started](getting-started.md) covers installation. [The tool catalog](intelligence-tools.md)
describes agent-facing operations. [Service deployment](intelligence.md) covers
remote connections. The old `attocode`, `attocodepy` and `attoswarm` commands and
`attocode-code-intel` forwarding belong to the [agent archive](legacy-agent.md).
