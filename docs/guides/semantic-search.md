# Search and optional embeddings

Use [the current search guide](../intelligence-search.md) for keyword/body
retrieval, source/test intent, candidate evidence, broad-query navigation and
ranking limitations. The [tool catalog](../intelligence-tools.md) describes MCP
arguments and follow-up requests.

Models are optional. Install `attocode-code-intel[semantic]` only when deliberately
configuring embeddings; a model can require substantial downloads and indexing
storage. No model is selected by the repository transition. A passing source
benchmark is not evidence of agent-outcome gains.

The former guide, including historical model trials and old agent paths, is
preserved in the [archive](https://github.com/eren23/attocode/blob/agent-archive-2026-10-16/docs/guides/semantic-search.md).
