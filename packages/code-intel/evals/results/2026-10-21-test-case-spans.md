callback-span hypothesis. macOS workspace aliases (`/var` versus `/private/var`)
caused the adapter to fail before extraction. The index caught that exception
and used file windows. All 2,088 candidate hit occurrences were file windows;
there were zero callback units. The earlier arithmetic rejection must not be
interpreted as evidence that correctly indexed callback spans are ineffective.

An independent author and reviewer grounded 24 new questions in pinned Express
and Prisma sources before that attempt. The questions are now consumed. Any
corrected comparison on them is development evidence, not fresh validation.
The initial failed source-copy attempt, fallback-only comparison, raw pages,
operators and earlier uncommitted report/archive are retained privately.

regression fails before the fix and passes afterward. Before any query, the

change. **No search ranking change is enabled in product.**

## Corrected, admitted development comparison

The rule recognizes literal `it`/`test` callbacks and single `.only`/`.skip`
forms in JavaScript/TypeScript test paths. Dynamic titles, arbitrary receivers
and parameterized DSLs are not inferred. It adds search-only body units, without
creating navigation definitions. Only short explicit test queries use the
alternate index; ordinary queries use the original index.

The corrected comparison ran three alternating rounds through actual compact
MCP delivery, requesting depths 5 and 24 with 2,000 and 8,000 token budgets.
Admission found 1,127 test-case windows from 1,119 distinct owners in Express,
and 4,809 windows from 3,935 owners in Prisma. Keyword and function/method-window
hashes match their baseline in each repository. The delivered results include
1,167 test-case hit occurrences, unlike the invalid initial attempt.

| Delivered evidence | Baseline | Candidate |
|---|---:|---:|
| Labeled query/file matches at 5 | 15 | 11 |
| Labeled query/file matches at 24 | 15 | 16 |
| Labeled excerpts at 5 | 4 | 6 |
| Labeled excerpts at 24 | 4 | 11 |

Counts are identical in all three rounds. There are zero new first-page file
matches. Express status validation, referrer lookup, `sendStatus`, and HEAD
fallback each lose a labeled file at five in every round: 12 loss observations
over four questions. Extra excerpt matches do not satisfy the frozen no-loss
rule. **Reject on consumed development; skip new fresh validation and do not
retune this rule.** This is not a held-out relevance gain or general search-quality
claim.

Warm p95 was 86.2/83.0/78.5 ms for baseline and 78.2/88.3/79.1 ms for candidate.
All three latency checks pass. All six ordinary-query raw control pairs match.
The two admitted workers took 27.609 seconds, with peak sampled RSS 188.3 MiB
and peak managed storage 135.3 MiB. Child cleanup and owned scratch removal pass.
No model, source download or cloud worker was used for this comparison.

## Replay and limits

The [decision](2026-10-21-test-case-spans-decision.json) binds the
[archive](2026-10-21-test-case-spans.tar.gz). Extract it outside the checkout and
run its `replay.py` with this repository and `packages/code-intel/src` on
`PYTHONPATH`. It verifies file hashes, recomputes all 288 admitted page judgments,
checks controls and representation admissions, and reproduces every gate without
retrieval or network access. The earlier invalid attempt is explicitly segregated
inside the archive and does not contribute to the development decision.

Public envelopes retain result data; private workspace metadata is omitted and
control follow-up roots use `$SOURCE_ROOT`. Source snippets, coordinates, ordering,
timings and judgments are unchanged; original response hashes are recorded.
Independent review checked 39 pinned label files, all request/order bindings,
835 coordinate-bearing delivered windows including controls, and all admitted
test-case hit identities. One metadata preview has no source coordinates and
never earns excerpt credit. Labels are source-bound and non-exhaustive; no agent
completion benefit is established.
